# edit-page

## 選択

1件を単一画面で作成・編集して保存するとき。例：顧客を新規登録／プロフィールを更新。

使わない条件：独立した設定群は`settings-page`、段階入力は`step-form`。

## 領域と状態

`h1`、入力領域、エラー概要、送信と取消、未保存の案内。項目には`FormField`を使う。

初期→入力→送信中→成功または失敗。入力エラーは値を保持し項目と結び付ける。`submitting`中は送信・取消を無効にして二重送信を防ぐ。`dirty`の離脱確認は利用側のルーターで実装する。

## データと操作

`variant`で作成・編集、`children`に入力、`onSubmit`・`onCancel`に操作、`submitting`・`error`・`dirty`に状態を渡す。検証規則と保存処理は利用側。通信、認可、ルーティングは利用側が担う。原本は`registry/new-york/patterns/edit-page/edit-page.tsx`。

## 狭い画面とアクセシビリティ

狭い画面では入力と操作を縦に並べる。エラー時は利用側が概要と項目を対応付け、最初の無効項目へフォーカスする。状態は読み上げ、フォーカスを送信中に奪わない。
