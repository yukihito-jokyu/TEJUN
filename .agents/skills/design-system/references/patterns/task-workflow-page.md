# task-workflow-page

## 選択

独立した作業を順序や完了状況を見ながら進めるとき。例：申請書類と本人確認／数日にわたる開設準備。

使わない条件：一続きの段階入力は`step-form`。

## 領域と状態

`h1`、完了件数、作業カード、各作業の再開先、全体完了後の行動。作業のURLと完了条件は利用側が渡す。

各作業は未開始・進行中・完了・問題あり。全体完了は`complete`または全作業完了から算出し、空の作業群は完了扱いにしない。

## データと操作

`tasks`に一意の`id`、見出し、状態、任意の`action`を渡す。`complete`で業務上の完了条件、`completionAction`で次の行動を渡す。通信、認可、ルーティングは利用側が担う。原本は`registry/new-york/patterns/task-workflow-page/task-workflow-page.tsx`。

## 狭い画面とアクセシビリティ

狭い画面ではカードを1列にする。カード見出しは`h2`、状態と完了件数を読み上げ、各再開先へキーボードで到達できる。
