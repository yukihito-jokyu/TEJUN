# settings-page

## 選択

複数の独立した設定群を確認・変更するとき。例：通知と表示設定／プライバシーと連携設定。

使わない条件：単一項目の変更や1件の編集は`edit-page`または直接の部品合成。

## 領域と状態

`h1`、設定群ごとの`SettingsSection`、各群の入力と保存操作。`dangerous`な群は末尾の「危険な設定」領域へ分離される。

群ごとに未変更→保存中→成功または失敗。`saving`中はその群の保存を無効にする。他群の状態は保持し、失敗後は値を保持して再試行できる。

## データと操作

`groups`の各要素へ一意の`id`、`content`、`onSave`、`saving`、`saved`、`error`、必要なら`dangerous`を渡す。値と保存処理は利用側。取り消せない変更には`destructive-action`を重ねて確認する。通信、認可、ルーティングは利用側が担う。原本は`registry/new-york/patterns/settings-page/settings-page.tsx`。

## 狭い画面とアクセシビリティ

狭い画面では群を1列に並べる。通常の群の見出しは`h2`、危険な設定の群は領域の`h2`の下で`h3`。保存結果は群の近くで読み上げる。
