# bulk-action

## 適用条件

複数件へ同じ処理を実行する場合。単一件への操作には適用しない。

## 操作と状態

`data-table`の`onSelectionChange`を使う。`selectionScope`を`page`または`filtered`に明示し、選択数と範囲を示す。実行前は`ui/alert-dialog`で対象と影響を確認し、処理中は再実行を防ぐ。部分失敗なら成功・失敗件数を残し、完了後は選択を解除する。

## 狭い画面とアクセシビリティ

狭い画面でも選択数と実行ボタンを操作可能にする。全選択はキーボードで操作できる。確認を閉じたら起点へフォーカスを戻し、結果を読み上げる。
